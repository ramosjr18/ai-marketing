# AI Marketing — repo rules

A prompt framework versioned in git. Markdown is the execution layer; code appears only
where an agent cannot reach (fetching, parsing, rendering). One company per repo.

## Company overview

@.claude/skills/company-blueprint/00-overview.md

If the import above is empty, the blueprint does not exist yet. Run `/setup` before any
other command. Do not guess company facts.

## Where things live

| What | Where |
|---|---|
| Company blueprint (truth) | `.claude/skills/company-blueprint/0*.md` — gitignored, generated by `/setup` |
| Blueprint templates | `.claude/skills/company-blueprint/templates/` — tracked |
| Workflows | `.claude/commands/*.md` |
| Source material | `documents/` — gitignored except `README.md` |
| Client cases | `clients/<slug>/` — gitignored except `README.md`, opened by `/client` |
| Client templates | `.claude/templates/client/` — tracked |

## Rules for every workflow

1. **Blueprint first.** Load the numbered file you need (`01`..`04`), not all of them.
   `00-overview.md` is already in context through this file.
2. **Never invent company facts.** A price, a client name, a metric or a claim that is not
   in the blueprint or in `documents/` does not exist. Ask, or leave it out.
3. **Propose, then write.** Anything that changes a permanent record (blueprint, a tracker,
   an outgoing message) is shown in full and approved before it is written or sent.
4. **Respect flags.** Each blueprint file carries `sections:` flags in its frontmatter. A
   block set to `false` is not there: do not read it, do not ask for it, do not fill it.
5. **Voice is law.** Anything written for the outside follows `04-voice.md`. Banned words
   are banned.
6. **Inference is labeled.** Anything deduced rather than sourced carries
   `[Inferred from <source> — review before relying on this]`.
7. **Approvals.** When `03-people.md` has `approvals: true`, a change to pricing, public
   copy or a new client goes to the person listed there before it happens.

## Conventions

- Framework files (commands, skills, templates) are in English. Blueprint *content* is in
  the company's `content_language` set during `/setup`.
- Placeholders in templates look like `[LIKE_THIS]`. A populated file never contains one.
- Sources sit next to facts: a URL or a `documents/` path.

## Git

This repo is public. **Only `master` is published.** Any other branch stays on the machine that
made it: working branches can carry the design journal, a populated blueprint or client
material, none of which belongs in a public history. A `pre-push` hook refuses anything but
`master`, and `--all` / `--mirror` are never used.
